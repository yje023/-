# 考核评价系统 — 统信 UOS 使用说明

## 操作步骤

### 第 1 步：把项目文件夹复制到 UOS 电脑

将整个 `qjqgbkhxt` 文件夹复制到 UOS 电脑上（桌面或任意位置）。

### 第 2 步：赋予脚本执行权限（首次使用）

右键点击 `一键启动.sh` → **属性** → **权限** → 勾选 **「允许作为程序执行」**。

如果是从 Windows 电脑复制过来的，这一步很重要，否则会提示"权限不够"。

### 第 3 步：运行一键启动脚本

**右键点击 `一键启动.sh` →「在终端中运行」**。

首次运行会提示输入管理员密码（自动安装 Python、Node.js 等依赖）。以后再启动直接秒开。

### 第 4 步：打开浏览器

脚本自动打开浏览器访问 `http://localhost:5000`。如未自动打开，请手动访问。

### 快捷方式（可选）

将 `uos/考核评价系统.desktop` 复制到桌面，双击即可一键启动。

---

## 常见问题

| 问题 | 解决 |
|------|------|
| 双击打开了文本编辑器 | 右键 → 在终端中运行 |
| 提示"权限不够" | 右键 → 属性 → 权限 → 勾选"允许作为程序执行" |
| 终端窗口一闪就关 | 右键一键启动.sh → 属性 → 权限 → 勾选"允许作为程序执行"，确保文件是从本文件夹直接使用的（未移动位置） |
| 应用商店安装的 Node.js 版本太旧 | `sudo apt install nodejs npm -y` |
| 安装依赖报错 | 先执行 `sudo apt update` |
| 端口 5000 被占用 | 关闭之前打开的终端窗口后重试 |
| 想固定到任务栏 | 将 `uos/考核评价系统.desktop` 复制到桌面 |
