# v1.5 开发日志 — 2026年6月4日

## 版本
**2026年6月4日 1.5版（任务引擎升级：状态机+审核驳回+下发分发+操作日志+任务书快照）**

## 变更内容

### 1. 任务状态机增强 (1A)
- 新增4个状态：draft(草稿)、rejected(已驳回)、confirmed(已确认)、completed(已完成)
- 完整流转链路：draft→pending→submitted→rejected→pending→submitted→reviewed→confirmed→completed
- 每个状态转换均通过专门端点，带严格状态校验
- 新增API端点：
  - `PUT /api/tasks/<id>/reject` — 驳回 (submitted→rejected)
  - `PUT /api/tasks/<id>/resubmit` — 重提 (rejected→pending)
  - `PUT /api/tasks/<id>/confirm` — 确认纳入任务书 (reviewed→confirmed)
  - `PUT /api/tasks/<id>/complete` — 标记完成 (confirmed→completed)
  - `GET /api/tasks/<id>/history` — 获取操作历史
- 现有端点状态校验增强：submit仅pending可提交、score仅submitted可评分、edit/delete阻止confirmed/completed
- 修改文件：models.py, app.py, routes/task.py, services/task_query.py

### 2. 任务下发流程 (1B)
- 新增 `POST /api/tasks/batch-distribute` 批量分发端点
- draft任务仅管理员/主考单位可见，被考核单位不可见
- 分发后状态变为pending，被考核单位可见并可提交
- 任务新增 `task_source` 字段：direct(直接创建)/dispatched(下发)/self_declared(自主申报预留)
- 新增 `distributed_at`、`distributed_by` 字段记录分发信息
- 前端：批量分发按钮、任务来源列、draft筛选选项

### 3. 操作日志 (1C)
- 新增 ProcessLog 模型：记录每次状态变更(action/from_status/to_status/operator/comment)
- 3个索引(idx_process_log_task_id/plan_id/action)
- 前端操作历史时间线(el-timeline)展示完整操作记录
- 所有状态变更操作(create/submit/reject/resubmit/review/confirm/complete/distribute)自动记录

### 4. 任务书快照 (1D)
- confirm操作时自动生成数据快照(snapshot_data JSON)，包含key_work/main_task/submissions/scores
- confirmed_at时间戳记录确认时间
- 已确认/已完成任务禁止编辑和删除（前后端双重校验）

### 5. 前端更新
- Tasks.vue：7种状态标签颜色(draft灰/pending蓝/submitted黄/rejected红/reviewed绿/confirmed蓝/completed绿)
- 操作按钮按角色+状态动态显示：驳回/审核/打分/确认/完成/重提/日志
- el-timeline操作历史弹窗
- 驳回原因弹窗
- 任务来源列(下发/直接)
- 批量分发按钮(仅draft任务)
- 更新文件：Tasks.vue, api/task.js

### 6. 数据库变更
- task表新增7个字段：rejection_reason, task_source, distributed_at, distributed_by, confirmed_at, completed_at, snapshot_data
- 新增process_log表
- 新增3个索引：idx_task_task_source, idx_process_log_*
