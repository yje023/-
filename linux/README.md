# 考核评价系统 — 麒麟 Linux 使用说明

## 操作步骤（3 步）

### 第 1 步：把整个项目文件夹复制到麒麟电脑

将 `qjqgbkhxt` 文件夹复制到麒麟电脑上（桌面或任意位置）。

### 第 2 步：右键运行脚本

进入项目文件夹的 `linux` 子目录，找到 **`一键启动.sh`**。

**右键点击 →「在终端中运行」**（或「以程序运行」）。

首次运行会提示输入管理员密码（安装依赖），之后不再需要。

### 第 3 步：打开浏览器

脚本会自动打开浏览器。如未自动打开，手动访问 `http://localhost:5000`。

---

## 以后再启动

直接在 `linux` 目录右键运行 `一键启动.sh` 即可，已安装过的依赖会自动跳过，秒开。

---

## 常见问题

| 问题 | 解决 |
|------|------|
| 双击打开了文本编辑器 | 右键 → 在终端中运行 |
| 提示"权限不够" | 右键 → 属性 → 权限 → 勾选"允许作为程序执行" |
| 端口 5000 被占用 | 关闭终端窗口后重试，或重启电脑 |
| 没有 Node.js | 脚本会自动安装，输入密码即可 |
| 麒麟软件商店的 Node 太旧 | `sudo apt install nodejs npm -y` |
